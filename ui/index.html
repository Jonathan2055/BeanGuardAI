What the data tells us

1. Class balance

Each class has the same number of images, so accuracy is a fair metric and the model cannot score well just by favouring one class.

2. Average colour per class

Healthy leaves have the highest green and blue values. Diseased leaves are less green, and angular leaf spot photos have more red/yellow from the brown lesions and yellowing. Colour helps, but the classes overlap a lot, so the model also needs texture and shape.

3. Per-class F1 score

This shows which disease the model finds hardest. Classes with lower F1 are the ones most often confused with another class (see the confusion matrix on the dashboard).
